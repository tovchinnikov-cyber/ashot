A-Shot

Нативная скриншотилка для Mac на Apple Silicon. Быстро, бесплатно, без Electron и без слежки.

⬇ Скачать A-Shot.dmg Исходники на GitHub

macOS 15+ · Apple Silicon · MIT license

Почему A-Shot

⚡️

Мгновенный запуск

Swift + AppKit + ScreenCaptureKit — никакого Electron и фризов при захвате.

⌨️

Глобальный хоткей

Работает даже когда в фокусе другое приложение — включая звонки в Zoom и Teams.

🖊️

Аннотации

Стрелки, прямоугольники и текст прямо на скриншоте перед копированием.

🖥️

Мультимонитор

Выделяй область на любом из подключённых экранов.

📋

Прямо в буфер

Один клик или ⌘C — и скриншот уже готов для вставки в чат.

🔒

Приватность

Без телеметрии, без аккаунта, без рекламы. Открытый исходный код.

Установка

  1. Скачайте A-Shot.dmg и перетащите A-Shot.app в Applications
  2. При первом запуске macOS покажет предупреждение Gatekeeper — это нормально: приложение подписано без платного Apple Developer ID. Откройте System Settings → Privacy & Security → Security и нажмите Open Anyway рядом с A-Shot
  3. Разрешите доступ Accessibility и Screen Recording, когда macOS спросит — без них хоткей и захват экрана не работают
  4. Готово — жмите ⌘⇧S (или свой хоткей из настроек) и выделяйте область
